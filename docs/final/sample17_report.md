# 어려운 케이스(sample17) 최종 실험

`my/samples/faces/samples/sample17.png`은 그동안 가장 잘 안 되던 샘플이다. 어린이 근접 촬영이고
**금속 보철 + 앞니 결손(검은 틈) + 총생**이 겹쳐 있으며, 이마가 잘린 클로즈업이라 얼굴 비율도 특수하다.
최종 실험 기준 설정으로 치아 / 고개 방향 / 웃는 정도를 다시 돌렸다.

- 스타일: `smile_final_smile_v3.yaml` (실험용), seed 0, 서버 기본 설정(fp8 가중치 + bf16 연산)
- 21건 전부 성공. 치아 편집 2.6초, 템플릿 사용 3.6초
- 결과물: [`outputs/final_sample17/`](../../outputs/final_sample17/) (폴더 설명은 그 안의 `README.md`)
- 지표: 치아 노란기 **b\*** (작을수록 희다), 고개 각도 **yaw**(도), **웃음**(MediaPipe blendshape), **입 벌림**(jawOpen)

## 요약

- **미백만으로는 이 케이스를 고치지 못한다.** 색은 밝아지지만 검은 틈과 금속이 그대로 남는다.
  **정렬을 같이 걸어야** 틈이 메워진다(정렬 100 + 미백 75).
- **고개 방향과 치아를 함께 바꿀 때는 "고개 → 치아" 순서가 가장 좋다.** 치아를 먼저 고치면 고개를 돌리는 단계에서
  치아가 다시 그려져 효과가 절반쯤 사라진다(b\* 2.6 → 5.0). 반대로 고개를 먼저 돌리고 치아를 inpaint하면 b\* 0.2로 가장 깨끗하다.
- **웃는 정도는 이 샘플에서 0(입 다물기)과 25(입 다문 미소)가 잘 동작한다.** 75/100은 이미 크게 웃고 있어 변화가 작다.
- 템플릿 이미지는 조합 프롬프트와 비슷한 수준이고, **템플릿만 쓰면 색이 덜 희다**(b\* 6.0). 112명 실험과 같은 결론이다.

## 1. 치아 (그룹 A)

입 영역만 inpaint했다. 얼굴의 나머지는 원본 픽셀 그대로다.

![치아 비교 (입 확대)](assets/s17_A_teeth_mouth.jpg)
![치아 비교 (얼굴 전체)](assets/s17_A_teeth_full.jpg)

| 설정 | b* | 눈으로 본 결과 |
| --- | --- | --- |
| 원본 | 6.7 | 금속 보철, 앞니 결손으로 생긴 검은 틈, 총생 |
| 미백 50 | 6.2 | **거의 변화 없음.** 틈·금속 그대로 |
| 미백 100 | **1.5** | 색은 확실히 희어짐. **검은 틈과 금속은 남음** |
| 정렬 100 | 7.5 | **틈이 메워지고 치열이 고르게 정리됨.** 색은 오히려 약간 누래짐 |
| **정렬 100 + 미백 75** | **2.6** | **틈 메움 + 흰색.** 가장 균형이 좋다 |
| 정렬 100 + 미백 100 | 2.0 | 더 희지만 인공적 |
| 템플릿 + 프롬프트 | 2.4 | 조합 프롬프트와 비슷. 금속이 조금 더 지워짐 |
| 템플릿만 (문장 없음) | 6.0 | 배열은 정리되지만 **색이 거의 안 변함** |

- **이 케이스의 핵심은 미백이 아니라 정렬이다.** "미백만"은 b\*만 낮출 뿐 구조적 결함(틈·금속)을 건드리지 않는다.
  정렬 문장이 들어가야 모델이 치아를 다시 배치하면서 틈을 메운다.
- 정렬만 걸면 b\*가 7.5로 오히려 올라간다. 새로 그린 치아가 주변 피부·잇몸 톤을 따라가기 때문으로 보인다. **정렬과 미백은 같이 써야 한다.**
- 금속 보철은 어떤 설정에서도 완전히 사라지지 않았다. 입꼬리 안쪽에 일부 남는다.

## 2. 고개 방향 + 치아 (그룹 B)

고개를 바꾸려면 마스크 없이 머리 전체를 다시 그려야 한다. 이때 치아도 함께 다시 그려지므로 **순서가 중요하다.**

![고개 + 치아 비교](assets/s17_B_pose_full.jpg)

| 방식 | yaw | b* | 결과 |
| --- | --- | --- | --- |
| 원본 | −3° | 6.7 | — |
| 고개만 | 13° | 6.9 | 고개는 돌아가고 치아는 그대로(틈 남음) |
| 한 번에 (조합 문장) | 13° | 3.8 | 고개 + 치아 모두 적용. 틈이 일부 남음 |
| 한 번에 (delta 덧셈) | 18° | 5.5 | 고개는 돌지만 **치아 효과가 약함** |
| 치아 → 고개 | 15° | 5.0 | **먼저 만든 흰 치아가 되돌아감** (2.6 → 5.0) |
| **고개 → 치아** | 13° | **0.2** | **가장 깨끗함.** 틈 메움 + 가장 흰 치아 |
| 템플릿 + 한 번에 | 13° | 3.7 | 조합 문장과 비슷 |

- **"고개 → 치아"가 가장 좋다.** 마지막 단계가 입 영역 inpaint라서, 치아 결과를 그 뒤에 덮어쓰는 것이 없다.
- **"치아 → 고개"는 쓰지 않는 게 좋다.** 고개 단계가 전체를 다시 그리면서 치아를 원래 상태 쪽으로 되돌린다.
  앞서 [README](README.md) 2.1절에서 관찰한 현상이 수치로 재확인됐다.
- `delta` 덧셈은 3축(고개+정렬+미백)에서 회전은 살아남았지만 치아 효과가 약했다(b\* 5.5 vs 조합 문장 3.8).
  4축에서 회전이 완전히 사라진 [embedding_modes.md](embedding_modes.md) 결과와 방향이 같다.
- 근접 촬영이라 고개를 돌리면 **구도가 넓어진다**(얼굴이 작아짐). 머리 전체를 다시 그리기 때문이며, 설정으로 막을 수 없다.

## 3. 웃는 정도 (그룹 C)

입꼬리와 볼이 움직이므로 아래 얼굴(`mouth` + `cheeks`)을 inpaint했다.

![웃는 정도 비교](assets/s17_C_smile_full.jpg)
![웃는 정도 (입 확대)](assets/s17_C_smile_mouth.jpg)

| 설정 | 웃음 | 입 벌림 | 결과 |
| --- | --- | --- | --- |
| 원본 | 0.73 | 0.04 | 윗니·아랫니가 모두 보이는 큰 웃음 |
| 웃음 0 (입 다물기) | **0.00** | 0.00 | **확실히 동작.** 치아가 완전히 가려짐 |
| 웃음 25 (입 다문 미소) | 0.45 | 0.00 | **동작.** 입을 다문 채 입꼬리만 올라감 |
| 웃음 75 (윗니만) | 0.65 | 0.03 | 입이 작아졌지만 **아랫니가 완전히 가려지지는 않음** |
| 웃음 100 (윗니+아랫니) | 0.59 | 0.03 | 원본과 비슷. 이미 크게 웃고 있어 변화 여지가 적음 |
| 웃음 75, 마스크 없음 | 0.66 | 0.02 | 마스크 있을 때와 거의 같음 → **마스크 범위 문제가 아님** |
| 웃음 75 + 정렬 + 미백 | 0.58 | 0.02 | b\* 3.7. 웃음과 치아가 함께 적용됨 |
| 웃음 100 + 정렬 + 미백 | 0.80 | 0.04 | b\* 4.3. 큰 웃음 + 흰 치아 |

- **0과 25는 이 어려운 샘플에서도 안정적이다.** 치아를 보여 주고 싶지 않은 경우에 바로 쓸 수 있다.
- **75/100은 효과가 작다.** 원본이 이미 큰 웃음이라 "더 웃게"나 "아랫니를 가리게" 할 여지가 적다.
  112명 실험에서 75가 19%만 동작한 것과 같은 한계다.
- 웃음 0은 b\*가 14.3으로 뛰는데, 이는 치아가 가려져 `teeth` 마스크가 입술 픽셀을 잡았기 때문이다. **색 지표로 해석하면 안 된다.**
- 웃음과 치아를 조합해도 서로 방해하지 않는다(C7, C8).

## 4. 이 케이스에서의 권장 설정

| 목적 | 설정 |
| --- | --- |
| 치아만 | `정렬 100 + 미백 75`, 입 영역 inpaint (`mouth`, dilate 16, feather 12) |
| 고개 + 치아 | **2단계**: ① 고개(마스크 없음) → ② 그 결과에 정렬+미백(입 영역 inpaint) |
| 치아를 감추고 싶을 때 | 웃음 0 또는 25, 아래 얼굴 inpaint |
| 템플릿 이미지 | 굳이 필요 없음. 조합 프롬프트와 결과가 비슷하고 요청이 1초 더 걸린다 |

## 5. 남은 문제

1. **금속 보철이 완전히 지워지지 않는다.** 입꼬리 안쪽에 남는다. 별도 지시문이 필요할 수 있다.
2. **고개를 돌리면 구도가 넓어진다.** 근접 촬영에서 두드러진다. 출력 후 원본 구도로 다시 crop하는 후처리를 검토할 만하다.
3. **웃음 75(윗니만)는 이 샘플에서도 약하다.** 문장 재설계가 필요하다([smile_template_report.md](../smile_tune/smile_template_report.md) 5장).
4. 이 보고서는 **환자 1명** 결과다. 같은 순서(고개 → 치아) 권장이 일반적으로 성립하는지는 여러 장으로 확인해야 한다.
