# 치아 템플릿 실험: 프롬프트만 vs 템플릿 이미지

`my/samples/dentals`에 추가한 템플릿 8종으로, 텍스트 프롬프트만 쓸 때와 치아 템플릿 이미지(`patient_tooth` 두 번째 이미지)를
함께 줄 때 결과가 어떻게 달라지는지 비교했다. **MICE는 쓰지 않았다**([mice_smile_report.md](mice_smile_report.md) — 제거 권장).

## 요약

- **같은 프롬프트(`align_whiten`) + 템플릿**: 결과는 텍스트가 정한다. 템플릿은 치아 모양에 약간 영향을 줄 뿐, 색이나
  교정 장치 같은 속성은 거의 옮겨지지 않는다 — 어떤 템플릿을 넣어도 "깨끗하고 가지런한 흰 치아"로 수렴한다.
- **"image 2의 치아로 바꿔라" 프롬프트(`teeth_from_template`) + 템플릿**: 템플릿의 속성이 실제로 옮겨진다 — 교정 와이어·브라켓,
  치아 모형의 누런 색, 삐뚤어진 배열까지. 옮겨지는 정도는 환자마다 다르다(sample18 강함, yellowteeth 약함).
- 두 방식 모두 얼굴 바깥과 신원은 그대로다(inpaint `inner_mouth`, 신원 0.93~0.97). 템플릿을 넣으면 요청당 약 0.3초 느려진다.
- 쓰임새: **치아 디자인 결과(미백·정렬)는 프롬프트만으로 충분하다.** 템플릿은 "특정 모양·장치를 보여 주기"(예: 교정 장치 미리보기)에
  쓸 수 있지만, 템플릿의 단점(색, 불규칙)까지 그대로 복사되므로 템플릿 이미지를 엄선해야 한다.

## 4. 해석

**템플릿 + 같은 프롬프트(`align_whiten`)**
- 결과가 모두 "깨끗하고 가지런한 흰 치아"다. 교정 장치·모형·삐뚤어진 템플릿을 넣어도 브라켓이 생기거나 누래지지 않는다
  (노란 정도 b: sample18 1.7~8.2, yellowteeth -0.2~2.1).
- 프롬프트만 대비 변화가 seed 변화와 비슷한 크기라(예: sample18 matmatAlpa 8.1 vs 10.9), 템플릿의 영향은 랜덤 차이 수준이다.
  예외로 good_teeth·bad_teeth(사람 입 사진)는 프롬프트만 대비 변화가 커서(yellowteeth 22.9) 치아 크기·배열에 영향을 준다.
- 즉 텍스트가 "흰 치아로 정렬"을 지시하면 템플릿은 보조 힌트에 그친다.

**템플릿 + 복사 지시(`teeth_from_template`)**
- 템플릿의 속성이 옮겨진다(위 확대 그림): bracket01 → 교정 와이어, bracket02 → 브라켓 + 누런 치아, dentiform → 모형처럼 누런 치아
  (sample18 노란 정도 1.7 → 14.8~18.1), bad_teeth → 불규칙한 배열.
- 프롬프트가 "image 2의 치아로 바꿔라"이므로 **템플릿의 좋은 점과 나쁜 점을 가리지 않는다.** 누런 모형을 넣으면 치아가 누래진다.
- 환자에 따라 강도가 다르다: yellowteeth는 대부분 흰 치아로 남고(노란 정도 0.7~3.6), 교정 장치도 약하게만 비친다.
- 선화(teeeth1)는 이번 두 환자에서는 윤곽선이 생기지 않았지만, 이전 실험에서 teeth04·sample17·teeth01에 윤곽선이 그려졌다
  ([mice_smile_report.md](mice_smile_report.md) 1.2절) — 환자에 따라 생기므로 선화 템플릿은 쓰지 않는 것을 권장.

## 5. 권장

1. **미백·정렬 결과에는 프롬프트만(`patient_only` + preset)을 쓴다.** 템플릿을 넣어도 품질이 좋아지지 않고 0.3초 느려진다.
2. 템플릿으로 특정 모양을 보여 주고 싶으면 **복사 지시 프롬프트**를 쓰되, 템플릿은 **원하는 결과 그대로의 실사 이미지**
   (흰색, 원하는 배열)만 쓴다. 누런 모형, 선화, 잘못된 치아 사진은 그 단점까지 복사된다.
3. 교정 장치 미리보기는 가능성이 보인다(sample18에서 브라켓·와이어가 생김). 다만 환자에 따라 약하게 나와서, 기능으로 쓰려면
   교정 전용 프롬프트(예: "add metal orthodontic brackets and an archwire to these teeth")를 따로 만들어 비교해 볼 만하다.
4. 템플릿 효과를 더 확실히 보려면 환자를 늘리고 seed를 여러 개로 평균내야 한다 — 이번은 2명 × seed 2개로 경향만 확인한 수준이다.
